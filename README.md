# LeetCode Clone

A fully-featured LeetCode clone with AI Agents, built with HTML, CSS, and JavaScript.

## Features

- **Problems List** - Browse and filter coding problems by difficulty and status
- **Code Editor** - Write and test code with syntax highlighting (CodeMirror)
- **AI Agents** - Get help from AI assistants (Hint, Code Review, Debug, etc.)
- **User Authentication** - Login/Signup with localStorage persistence
- **Contest System** - Participate in coding contests
- **Discussion Forum** - Community discussions and Q&A
- **Premium Plans** - Subscription pricing page
- **User Profile** - Track progress, achievements, and statistics
- **Dark Theme** - Beautiful dark mode UI
- **Responsive Design** - Works on desktop and mobile

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Main problems list |
| `problem.html` | Individual problem with code editor |
| `login.html` | Login/Signup page |
| `agents.html` | AI Agents chat interface |
| `contest.html` | Coding contests |
| `discuss.html` | Discussion forum |
| `premium.html` | Premium subscription plans |
| `profile.html` | User profile and statistics |

## AI Agents (Unique Feature)

- **Hint Agent** - Progressive hints without spoilers
- **Code Review Agent** - Code optimization suggestions
- **Explain Agent** - Algorithm explanations
- **Debug Agent** - Find and fix bugs
- **Complexity Agent** - Time/Space complexity analysis
- **Alternative Agent** - Different solution approaches

## Technologies

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- JavaScript (ES6+)
- CodeMirror (Code Editor)
- Font Awesome (Icons)
- localStorage (Data Persistence)

## Getting Started

1. Open `index.html` in your browser
2. Create an account or login
3. Start solving problems!
